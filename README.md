# ♻️ Smart Garbage Management System

A location-based smart garbage management website designed to improve
garbage collection and municipal waste management.

## 🌐 Live Website

👉 https://psuhirtha290-dot.github.io/location-based-garbage-management-system/

> The website link will work after GitHub Pages is enabled.

## 📌 Project Overview

The Smart Garbage Management System connects citizens and municipal
staff through a simple web platform.

Citizens can report garbage problems with their location and details,
while municipal staff can monitor complaints, smart bins and garbage
collection vehicles.

## ✨ Features

### 👤 Citizen

- Citizen registration
- Citizen login
- Report garbage problems
- Add complaint description
- Add location
- Add photo
- View personal complaints
- Track complaint status

### 🏢 Municipal Staff

- Staff login
- Staff dashboard
- View citizen complaints
- Update complaint status
- Assign garbage trucks
- Monitor smart bins
- Identify bins with 90% or higher fill level
- Monitor garbage collection vehicles
