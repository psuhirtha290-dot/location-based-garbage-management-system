# SmartClean
Location-Based Smart Garbage Management System.

Colour themes:
- Home: White + Blue
- People/Citizen: White + Maroon
- Staff/Admin: Purple + White

Files: index.html, style.css, script.js

Demo staff login: staff@smartclean.com / staff123

This is a frontend-only prototype. Data is stored in browser localStorage, so it is suitable for GitHub Pages demos but is not a secure shared production backend.

GitHub Pages: Repository Settings → Pages → Deploy from branch → main → /(root) → Save.
